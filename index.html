讓 AI agent 用一行指令
看見並操作瀏覽器

Playwright CLI（@playwright/cli）是 Microsoft 為 coding agent 打造的命令列瀏覽器自動化工具。
它把頁面快照與截圖存到磁碟、只回傳檔案路徑，讓 agent 自己決定要讀什麼——同一個瀏覽器任務，token 用量可比 Playwright MCP 少約 4 倍。

這份指南涵蓋什麼？

不只是指令表，更講清楚 Playwright CLI 為 AI agent 而生的設計取捨

🧭
Playwright CLI 是什麼
Microsoft 官方、專為 coding agent 設計的命令列瀏覽器介面，用 shell 指令取代 MCP 工具 schema。
🪙
token 經濟學
快照與截圖只存磁碟、不進 context。官方 benchmark：同任務 114k tokens（MCP）對 27k（CLI）。
🔁
snapshot → ref → 操作
核心迴圈拆解：讀 YAML 快照拿 e12 這種元素引用，直接 click / fill，不用寫 CSS selector。
📖
完整指令參考
Core / Navigation / Keyboard / Mouse / Tabs / Storage / Network / DevTools 全部 50+ 指令一次整理。
🤝
Claude Code / Codex 整合
兩層安裝模型、skill 探索驗證、named session 隔離，以及 skills-less fallback。
🔍
探索性測試工作流
charter → 場景 → 執行 → 報告，MCP 探索、CLI 固化的混搭策略，把 AI token 花在刀口上。
