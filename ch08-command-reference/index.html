第 8 章 · Part 3：核心操作模型

完整指令參考

因為資料留磁碟、不燒 context，CLI 敢一次開放整組指令。

ℹ️
指令面會隨版本擴充

本章以 @playwright/cli 0.1.x（約 v0.1.19）為準。實際以你安裝版本的 playwright-cli --help 為準；MCP 預設關掉的很多指令，CLI 這裡都預設可用。

Core（核心操作）

open [url]                 # 開瀏覽器，可選擇直接導航
goto <url>                 # 導航到網址
close                      # 關閉頁面
type <text>                # 對可編輯元素輸入文字
click <ref> [button]       # 點擊
dblclick <ref> [button]    # 雙擊
fill <ref> <text>          # 填入文字
fill <ref> <text> --submit # 填入後按 Enter
drag <startRef> <endRef>   # 兩元素間拖放
drop <ref> --path=<file>   # 把外部檔案拖放到元素上
hover <ref>                # 懸停
select <ref> <val>         # 下拉選單選項
upload <file>              # 上傳一或多個檔案
check <ref> / uncheck <ref>
snapshot                   # 取頁面快照（見第 7 章）
find <text> / find --regex <pattern>
eval <func> [ref]          # 在頁面或元素上執行 JS
dialog-accept [prompt] / dialog-dismiss
resize <w> <h>

eval 兩種常見用法：

playwright-cli eval "document.querySelectorAll('[data-testid=trend]').length"
playwright-cli eval "el => el.textContent" e5

Navigation / Keyboard / Mouse

# Navigation
go-back / go-forward / reload

# Keyboard
press <key>                # 例如 a、arrowleft、Enter
keydown <key> / keyup <key>

# Mouse
mousemove <x> <y>
mousedown [button] / mouseup [button]
mousewheel <dx> <dy>

Save as（截圖 / PDF）

screenshot [ref]              # 整頁或某元素
screenshot --filename=f.png
screenshot --hires            # 以完整 device pixel ratio 擷取
pdf / pdf --filename=page.pdf

Tabs（分頁）

tab-list
tab-new [url]
tab-close [index]
tab-select <index>

Storage

state-save [filename] / state-load <filename>

cookie-list [--domain] / cookie-get <name> / cookie-set <name> <val>
cookie-delete <name> / cookie-clear

localstorage-list / localstorage-get <key> / localstorage-set <k> <v>
localstorage-delete <k> / localstorage-clear

sessionstorage-list / sessionstorage-get <k> / ... / sessionstorage-clear

storage 與 session 的完整用法見 第 10 章。

Network

route <pattern> [opts]     # mock 網路請求
route-list                # 列出生效中的 route
unroute [pattern]         # 移除 route

細節與範例見 第 11 章。

DevTools

console [min-level]           # 列出 console 訊息
requests                      # 載入頁面後的所有網路請求
request <index>               # 某個請求的細節
run-code <code> / run-code --filename=f   # 執行 Playwright 程式片段
tracing-start / tracing-stop
recording-start / recording-stop         # 停止時印出對應 Playwright code
video-start [filename] / video-chapter <title>
video-show-actions / video-hide-actions / video-stop
show / show --annotate       # 開視覺儀表板
generate-locator <ref>       # 為元素產生穩定的 Playwright locator
highlight <ref> [--style= | --hide]

錄製、trace、影片見 第 12 章；show 儀表板見 第 13 章。

Open 參數與 attach

open --browser=chrome
open --mobile
open --device="iPhone 15"
open --persistent / open --profile=<path> / open --config=file.json
attach --extension=chrome     # 經 Playwright 擴充連既有瀏覽器
attach --cdp=chrome           # 依 channel 連 Chrome/Edge
attach --cdp=<url>            # 經 CDP endpoint 連
detach                        # 卸離但不關外部瀏覽器
delete-data                   # 刪除預設 session 的使用者資料

Sessions

-s=name <cmd>      # 在命名 session 執行指令
-s=name close      # 關掉某個命名瀏覽器
-s=name delete-data
list               # 列出所有 session
close-all           # 關掉所有瀏覽器
kill-all            # 強制殺掉所有瀏覽器進程
