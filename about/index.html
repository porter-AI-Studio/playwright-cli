關於本書與資料來源

一本社群整理的非官方指南，內容以 Playwright 官方文件為準。

適合誰讀

ℹ️
先備知識

本書假設你已經會基本的 Node.js／npm 操作與終端機（terminal）使用，並且對 Claude Code 或 Codex 這類 AI coding agent 有初步概念。如果這兩項你都還不熟，建議先跑完 Node.js 官方入門教學或 Claude Code 的安裝流程，再回頭從 第 1 章 開始讀。

這本書是怎麼寫出來的

本書以三類公開資料為骨幹，交叉比對後整理而成：官方來源（microsoft/playwright-cli GitHub README、npm 上的 @playwright/cli 頁、playwright.dev/agent-cli）、深度分析文、以及實戰教學。

⚠️
目前不是第一手實測

撰寫時尚未在本機完整跑過一輪 @playwright/cli session（安裝 → install --skills → TodoMVC 迴圈 → 留 snapshot / 截圖 / token 數）。書中指令與流程來自官方文件與第三方轉述，實測驗證列為待補項目。
